# 数据并行编程

![image-20260603171636741](https://cdn.jsdelivr.net/gh/ub-w/Article-images@main/Typoraimage-20260603171636741.png)

我们从向量并行加法引入，上面是一个CPU遍历执行的函数。那如果要在GPU上执行呢？

![image-20260603171847846](https://cdn.jsdelivr.net/gh/ub-w/Article-images@main/Typoraimage-20260603171847846.png)

我们需要进行将CPU的数据转移到GPU上，这个在物理上实现的技术是PCIE。

同时，我们需要执行以下五个步骤：

**步骤1：分配GPU内存**

```
cudaError_t cudaMalloc(void** devPtr, size_t size)
```

- `devPtr`：返回分配内存的指针（二级指针）
- `size`：分配字节数
- 返回值：错误码

**步骤2：从主机拷贝到GPU**

```
cudaError_t cudaMemcpy(void* dst, const void* src, size_t count, cudaMemcpyKind kind)
```

**参数说明**：

| 参数    | 含义              |
| :------ | :---------------- |
| `dst`   | 目标地址（GPU端） |
| `src`   | 源地址（主机端）  |
| `count` | 拷贝字节数        |
| `kind`  | 传输方向          |

**cudaMemcpyKind常用值**：

- `cudaMemcpyHostToDevice`：主机 → 设备
- `cudaMemcpyDeviceToHost`：设备 → 主机
- `cudaMemcpyDeviceToDevice`：设备 → 设备

**步骤3：启动GPU内核**

**内核启动配置**：

```
kernel<<<gridDim, blockDim, sharedMemSize, stream>>>(参数)
```

| 参数            | 含义                 |
| :-------------- | :------------------- |
| `gridDim`       | 网格中的线程块数量   |
| `blockDim`      | 每个线程块中的线程数 |
| `sharedMemSize` | 动态共享内存大小     |
| `stream`        | CUDA流               |

**步骤4：从GPU拷贝回主机**

**步骤5：释放GPU内存**

```
cudaError_t cudaFree(void* devPtr)
```

> ⚠️ **注意**：必须释放所有分配的GPU内存，否则会造成**内存泄漏**

函数通过关键字，来在编译的时候区分在何处运行。

```c++
#include"stdio.h"
#include"timer.cuh"
#include"../tools/common.cuh"

#define CYAN   "\033[36m"
#define RESET  "\033[0m"
#define GREEN  "\033[32m"

void printElapsedTime(Timer timer, const char* msg, const char* color) {
    float ms = getElapsedTime(timer);
    printf("%s%s: %.3f ms%s\n", color, msg, ms, RESET);
}

void vecadd_cpu(float* x, float* y, float* z, int N){
    for(unsigned int i = 0; i < N; ++i){
        z[i] = x[i] + y[i];
    }
}

__global__ void vecadd_Kernel(float* x, float* y, float* z, int N){
    unsigned int i = blockDim.x*blockIdx.x + threadIdx.x;
    if(i < N){
        z[i] = x[i] + y[i];
    }
}

void vecadd_gpu(float* x, float* y ,float* z, int N){
    //Allocate GPU memory
    float *x_d, *y_d, *z_d;
    cudaMalloc((void**)&x_d, N*sizeof(float));
    cudaMalloc((void**)&y_d, N*sizeof(float));
    cudaMalloc((void**)&z_d, N*sizeof(float));

    //Copy to the GPU
    ErrorCheck(cudaMemcpy(x_d, x, N*sizeof(float), cudaMemcpyHostToDevice), __FILE__, __LINE__);
    ErrorCheck(cudaMemcpy(y_d, y, N*sizeof(float), cudaMemcpyHostToDevice), __FILE__, __LINE__);

    //Run the GPU code(launch a grid of threads)
    Timer timer;
    startTime(&timer);
    const unsigned int numThreadsPerBlock = 512;
    const unsigned int numBlocks = (N + 512 -1)/512;
    vecadd_Kernel<<< numBlocks, numThreadsPerBlock >>>(x_d, y_d, z_d, N);
    stopTimer(&timer);
    printElapsedTime(timer, "cpu kernel time", GREEN);
    ErrorCheck(cudaGetLastError(), __FILE__, __LINE__);
    ErrorCheck(cudaDeviceSynchronize(), __FILE__, __LINE__);

    //Copy from the GPU
    ErrorCheck(cudaMemcpy(z, z_d ,N*sizeof(float), cudaMemcpyDeviceToHost), __FILE__, __LINE__);

    //Deallocate GPU memory
    cudaFree(x_d);
    cudaFree(y_d);
    cudaFree(z_d);
}

int main(int argc, char**argv){
    cudaDeviceSynchronize();

    //Allocate memory and inistialize data
    Timer timer;
    unsigned int N = (argc > 1)?(atoi(argv[1])):(1 << 25);
    float* x = (float*) malloc(N*sizeof(float));
    float* y = (float*) malloc(N*sizeof(float));
    float* z = (float*) malloc(N*sizeof(float));
    for (unsigned int i = 0; i < N; ++i){
        x[i] = rand();
        y[i] = rand();
    }

    //Vector addition on CPU
    startTime(&timer);
    vecadd_cpu(x, y, z, N);
    stopTimer(&timer);
    printElapsedTime(timer, "cpu time", CYAN);

    //Vector addtion on GPU
    startTime(&timer);
    vecadd_gpu(x, y, z, N);
    stopTimer(&timer);
    printElapsedTime(timer, "gpu time", CYAN);

    //Free memory
    free(x);
    free(y);
    free(z);
}
```

```
cpu time: 115.878 ms
cpu kernel time: 1.671 ms
gpu time: 42.422 ms
```
