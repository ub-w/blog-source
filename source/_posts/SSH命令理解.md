# SSH命令理解

## 1.`-R` 参数：Remote Port Forwarding（远程端口转发）

```
ssh -R 远程端口:目标地址:本地端口 用户名@远程服务器
```

```
ssh -R 8888:127.0.0.1:7897 myserver
```

```
远程服务器 (myserver)           SSH隧道           你的本地电脑
       |                                           |
       |  ❌ 无法直接访问外网                      |  ✅ 有 Clash 代理
       |                                           |
       +--- 访问 http://127.0.0.1:8888 ---> 转发 --+---> 127.0.0.1:7897 (Clash) ---> 互联网
```

**在远程服务器上执行任何网络请求时**，只要连接到 `127.0.0.1:8888`，流量就会被**通过 SSH 隧道"推送"回你的本地电脑**，然后由你的 Clash 代理发出。

## 2.`-L` 参数：Local Port Forwarding（本地端口转发）

```
ssh -L 本地端口:目标地址:远程端口 用户名@远程服务器
```

```
ssh -L 8080:内部网站.com:80 myserver
```

```
你的本地电脑               SSH隧道           远程服务器 (myserver)
       |                                           |
       |  ❌ 无法直接访问内部网站                  |  ✅ 能访问内部网络
       |                                           |
       +--- 访问 http://127.0.0.1:8080 --> 转发 ---+---> 内部网站.com:80
```

**在你的本地电脑上访问** `127.0.0.1:8080` 时，流量会被**通过 SSH 隧道发送到远程服务器**，由远程服务器去访问 `内部网站.com`，然后把结果传回来。
